Algorithm & boundaries

A saturation-first greedy coloring establishes a verified upper bound. A greedy clique witness establishes a lower bound. Exact backtracking tries each unresolved color count, choosing the uncolored vertex with the most distinct neighbor colors, then highest degree, then input order.

A completed failed search raises the lower bound. A found coloring lowers the upper bound. Equal bounds prove optimality. If the global search-node budget is exhausted, the unresolved interval is retained; the app never labels an unresolved palette impossible.

This is unweighted vertex coloring on simple undirected graphs. It does not support preassigned colors, register classes, spills, scheduling durations, or distributed solving. Search can grow exponentially; a web worker keeps the bounded computation off the interface thread.
